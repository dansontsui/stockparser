# 00878股價自動獲取程式

本專案提供多種方式來自動獲取國泰永續高股息ETF (00878) 的近一個月股價資料，並存入SQLite資料庫。

## 檔案說明

### 1. `get_00878_stock_price.py` (完整版)
- **功能**: 使用requests套件直接從台灣證券交易所API獲取資料
- **優點**: 功能完整，錯誤處理完善，支援重試機制
- **缺點**: 需要安裝requests和pandas套件
- **使用方式**: `python get_00878_stock_price.py`

### 2. `simple_00878.py` (簡化版)
- **功能**: 使用Python內建urllib套件獲取資料
- **優點**: 不需要額外安裝套件，僅使用Python標準庫
- **缺點**: 功能相對簡單
- **使用方式**: `python simple_00878.py`

### 3. `get_00878_with_existing.py` (整合版)
- **功能**: 使用現有的stkfunction模組獲取資料
- **優點**: 整合現有程式碼，重用已有功能
- **缺點**: 依賴現有模組和pandas
- **使用方式**: `python get_00878_with_existing.py`

### 4. `get_00878_simple.py` (推薦版)
- **功能**: 使用現有stkfunction模組，不依賴pandas
- **優點**: 整合現有功能，僅使用標準庫處理CSV
- **缺點**: 無
- **使用方式**: `python get_00878_simple.py`

### 5. `run_00878.bat` (批次檔)
- **功能**: Windows批次檔，提供選單選擇不同版本執行
- **使用方式**: 雙擊執行或在命令提示字元中執行

## 資料庫結構

程式會在SQLite資料庫中建立 `stock_prices_00878` 表格，包含以下欄位：

| 欄位名稱 | 資料型態 | 說明 |
|---------|---------|------|
| date | TEXT | 交易日期 (YYYY-MM-DD) |
| stock_code | TEXT | 股票代號 (00878) |
| stock_name | TEXT | 股票名稱 (國泰永續高股息) |
| trade_volume | INTEGER | 成交股數 |
| trade_value | INTEGER | 成交金額 |
| open_price | REAL | 開盤價 |
| high_price | REAL | 最高價 |
| low_price | REAL | 最低價 |
| close_price | REAL | 收盤價 |
| price_change | REAL | 漲跌價差 |
| transaction_count | INTEGER | 成交筆數 |
| created_date | TEXT | 資料建立時間 |

## 使用步驟

### 方法一：使用推薦版 (最佳選擇)
1. 確保Python環境可用
2. 執行: `python get_00878_simple.py`
3. 或雙擊執行: `run_00878.bat` 選擇選項2

### 方法二：使用簡化版
1. 確保Python環境可用
2. 執行: `python simple_00878.py`
3. 或雙擊執行: `run_00878.bat` 選擇選項1

### 方法三：使用完整版
1. 安裝必要套件: `pip install requests pandas`
2. 執行: `python get_00878_stock_price.py`
3. 或雙擊執行: `run_00878.bat` 選擇選項3

### 方法四：使用整合版
1. 確保pandas已安裝: `pip install pandas`
2. 執行: `python get_00878_with_existing.py`

## 程式功能

### 主要功能
- 自動獲取00878近30天的股價資料
- 將資料存入SQLite資料庫
- 避免重複資料 (使用PRIMARY KEY約束)
- 顯示最近10天的股價資料
- 統計資料筆數

### 資料來源
- 台灣證券交易所 (TWSE) 官方API
- API網址: `https://www.twse.com.tw/exchangeReport/STOCK_DAY`

### 錯誤處理
- 網路連線失敗重試機制
- 資料格式錯誤處理
- 資料庫操作異常處理
- 詳細的錯誤日誌記錄

## 注意事項

1. **API限制**: 台灣證券交易所API有請求頻率限制，程式已加入延遲機制
2. **資料格式**: 原始資料使用民國年格式，程式會自動轉換為西元年
3. **假日資料**: 週末和國定假日無交易資料
4. **資料完整性**: 程式會自動處理缺失值和異常資料

## 疑難排解

### 常見問題
1. **ModuleNotFoundError**: 請安裝相關套件或使用簡化版
2. **網路連線失敗**: 檢查網路連線或稍後重試
3. **資料庫鎖定**: 確保沒有其他程式正在使用資料庫檔案

### 日誌檔案
- 完整版會產生 `00878_stock_price.log` 日誌檔案
- 可查看詳細的執行過程和錯誤訊息
